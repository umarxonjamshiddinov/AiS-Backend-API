# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions, or pull requests.

If private vulnerability reporting is enabled, use the repository's **Security** tab and select **Report a vulnerability** to send a private report to the maintainers. Do not publish vulnerability details in issues, discussions, or pull requests.

If private vulnerability reporting is unavailable, use a private contact method published by the maintainers to ask for a secure reporting channel. The repository does not publish an alternate security contact. Do not include vulnerability details, credentials, or other sensitive material in a public issue.

Include only the information needed to understand and reproduce the issue: affected component/version, impact, and concise reproduction steps. Do not include real user data, live credentials, or third-party data. The maintainers will acknowledge and coordinate follow-up through the private channel.

## Supported versions

This project does not currently document a supported-version policy. Please include the version or commit you tested so maintainers can assess the affected releases.
