# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions, or pull requests.

If GitHub's private vulnerability reporting is enabled for this repository, use the repository's **Security** tab and select **Report a vulnerability**. This sends the report privately to the maintainers.

If private reporting is unavailable, contact the maintainers through the existing support address, `support@myais.uz`, and ask for a private reporting channel. Do not include exploit details, credentials, or other sensitive material until a private channel has been confirmed.

Include only the information needed to understand and reproduce the issue: affected component/version, impact, and concise reproduction steps. Do not include real user data, live credentials, or third-party data. The maintainers will acknowledge and coordinate follow-up through the private channel.

## Supported versions

This project does not currently document a supported-version policy. Please include the version or commit you tested so maintainers can assess the affected releases.
